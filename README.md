## 프로젝트명
FITBOA 체형 기반 패션 스타일링 구독 서비스

## 수행 시기
2022년

## 프로젝트 소개
사용자의 체형 정보를 기반으로 개인에게 적합한 패션 및 스타일링 콘텐츠를 제공하고, 월간·연간 구독을 통해 스타일링 서비스를 이용할 수 있도록 개발한 패션 구독 플랫폼.

사용자가 자신의 신체 사이즈와 체형 정보를 등록하면 체형 유형에 맞는 스타일링 가이드와 콘텐츠를 확인할 수 있으며, 구독 상품 결제, 프로모션, 리뷰, 문의, 마이페이지 등의 사용자 기능을 제공한다.

## 주요 기술
- Vue.js 2
- JavaScript
- Vuex
- Vue Router
- Axios
- vue-infinite-loading
- vue-slick-carousel
- Day.js
- SHA-256
- MariaDB
- KG이니시스 결제 연동
- HTML / SCSS

※ 전체 서비스 Backend는 Node.js / Express 기반으로 구성됨.

## DB 설계
체형 기반 스타일링과 구독 서비스를 운영하기 위한 데이터베이스 구조를 설계하였다.

주요 데이터 영역:
- 사용자
- 사용자 신체정보
- 체형정보
- 스타일링 콘텐츠
- 스타일링 리뷰
- 구독 상품
- 사용자 구독정보
- 결제정보
- 결제 카드
- 프로모션
- 북마크
- 문의
- 공지사항 / FAQ

사용자 → 체형정보 → 스타일링 콘텐츠와 사용자 → 구독상품 → 결제 → 프로모션 등의 서비스 흐름을 고려하여 Entity 관계와 DB 구조를 설계하였다.

- 서비스 전체 DB 구조 설계

## 프로젝트 내 역할
일반 Backend API 및 서버 비즈니스 로직을 제외한 Frontend 전체 개발과 DB 설계를 담당하였다.

Vue.js를 기반으로 회원가입부터 체형정보 등록, 스타일링 콘텐츠 조회, 구독 신청, 결제, 프로모션, 리뷰 및 마이페이지까지 사용자 서비스 전반을 구현하였다.

서비스 데이터 구조를 설계하고 사용자, 신체정보, 체형, 스타일링 콘텐츠, 구독, 결제 및 프로모션 등의 관계를 정의하여 DB 및 ERD를 설계하였다.

또한 KG이니시스 결제 서비스를 연동하여 월간·연간 구독상품 선택부터 주문정보 생성, 결제 요청 데이터 구성, Hash 생성, 프로모션 할인 및 최종 결제금액 계산 등 사용자 결제 흐름을 구현하였다.

Node.js / Express 기반 일반 Backend API 및 서버 비즈니스 로직은 다른 개발자가 담당하였다.
